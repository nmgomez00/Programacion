## Solo se aplican para POO

## Hay tres tipos de patrones de diseño

- Creacionales: Creacion de Objetos
  - Singleton
  - Factory
  - Builder
- Estructurales: Como se relacionas con otros objetos
  - Adapter
  - Decorator
  - Facade
- Comportamiento:Como se relacionan entre sí

  - Observer
  - strategy
  - Memento
    (entre otros ejemplos)

- Propósito

  - Problema
  - Solución

- Motivacion (mas detalles del problema y solucion)

- Estructura (diagrama de clases)
- Ejemplo con Código
